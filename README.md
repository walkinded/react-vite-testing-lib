React + TypeScript + Redux Toolkit: Pet-проект по тестированию
Этот пет-проект создан для изучения и отработки навыков написания Unit-тестов и UI/Интеграционных тестов на современном фронтенд-стеке. В качестве основы реализовано небольшое приложение с маршрутизацией, стейт-менеджером и запросами данных, а основной упор сделан на покрытие кода тестами.

Стек технологий
Основной стек:

Vite — сборщик и dev-сервер

React — UI-библиотека

TypeScript — типизация

Redux Toolkit — управление состоянием

React Router DOM — маршрутизация

Тестирование:

Vitest — тест-раннер (быстрый аналог Jest)

React Testing Library — тестирование компонентов (UI)

@testing-library/user-event — эмуляция действий пользователя

@testing-library/jest-dom — дополнительные матчеры (например, toBeInTheDocument)

Структура проекта
src/components/ — переиспользуемые компоненты (Counter, NavBar). Рядом с каждым компонентом лежит его тест (\*.test.tsx).

src/pages/ — страницы приложения (MainPage, UsersPage, UserDetailsPage, AboutPage, ErrorPage).

src/router/ — конфигурация маршрутизации (AppRouter.tsx).

src/store/ — Redux-хранилище:

reducers/counterReducer.ts — слайс для счетчика.

reducers/selectors/ — селекторы (с примерами их Unit-тестов).

store.ts — конфигурация store (экспортирует фабрику setupStore для изоляции тестов).

src/users/ — логика для работы с пользователями и её тесты.

vitest.setup.ts — глобальная настройка тестового окружения (подключение jest-dom).

Что и как тестируется?
В проекте отработаны следующие подходы к тестированию:

Unit-тесты чистой логики (Redux):

Тестирование редьюсеров (counterReducer.test.ts): проверка initialState, обработки экшенов (increment, decrement, reset) и иммутабельности.

Тестирование селекторов (getCounterValue.test.ts): проверка корректного извлечения данных из стейта.

UI-тесты компонентов (React Testing Library):

Проверка начального рендера (по дефолтному стейту и с использованием preloadedState).

Интеграционные тесты: клики по кнопкам (userEvent) и проверка того, как обновляется UI (например, Counter.tsx).

Использование кастомного рендера (обертки в <Provider>) для проверки вызовов dispatch.

Как запустить

Клонируйте репозиторий и установите зависимости:
bash
npm install

Запустите приложение в режиме разработки:
bash
npm run dev

Запустите тесты (в режиме наблюдения - watch mode):
bash
npm run test

Посмотреть отчет о покрытии кода тестами (Coverage):
bash
npm run test -- --coverage

Проект создан в учебных целях для глубокого понимания процесса тестирования React-приложений с Redux.
